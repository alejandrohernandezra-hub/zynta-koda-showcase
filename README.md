# Zynta-Koda showcase (work in progress)

The public page of Zynta-Koda, a supply-chain planning engine for food and
drink manufacturers: https://alejandrohernandezra-hub.github.io/zynta-koda-showcase/

Everything here is generated. The companies, their data and the disruptions
are fictional; every number on the page is what the engine computed on them.
The engine itself lives in a private repository. Not for search engines yet.

Built by [Alejandro Hernandez Ramos](https://www.linkedin.com/in/alejandroh1/).
